# Reports

This directory holds human-readable reports about substantial work done in the
repo.

Current layout:

- `reports/collector/` holds collector and VAPTR debugging or validation notes
- `reports/kernel/` holds syscall, kernel build, install, and runtime
  checkpoints
- `reports/archive/` holds older branch-audit and handoff docs that are useful
  for history but are not active milestones

Guidelines:

- keep milestone or validation reports here
- keep transient planning notes out of the repo root
- prefer one report per major task rather than many tiny scratch notes
- use `cleaningup.md` at the repo root only for the current cleanup campaign
